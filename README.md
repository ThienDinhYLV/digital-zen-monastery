# Thiền Viện Tĩnh Lặng — Digital Zen Monastery V1.4

**Engineering rebuild / acceptance candidate**, not a finished photorealistic meditation product. Source project for https://github.com/ThienDinhYLV/digital-zen-monastery.

## What changed from V1.3

- Actual original **skinned GLB monk** in repository: 11 bones, an idle animation, 55 mesh parts. NOT a photorealistic scan. The model is generated by `python3 tools/generate_monk.py` and verified structurally.
- A scenic environment with a restrained wooden pavilion, 3D pond, stone path, instanced foliage, cinematic **2D** backplate from the already-approved concept, responsive UI.
- Traced introductory teaching library: MN118, MN10, SN56.11, AN3.65. Summaries are labelled as summaries; sources link to SuttaCentral. Offline reply cannot invent source citations.
- Optional backend scaffold with rate limit, origin allowlist and keys kept on server; **not deployed by GitHub Pages**.
- PWA base-path-safe manifest and service worker, updated CSS, regression tests and GitHub Actions QA gate.

## Quick start on macOS

```bash
cd ~/Projects/digital-zen-monastery
npm install
npm test
npm run dev
```

To inspect a production build locally:

```bash
npm run build
npm run preview
```

The first launch may load Google fonts from the internet. The interface has local system-font fallbacks and can function without those fonts.

## GitHub Pages

Vite uses `GITHUB_REPOSITORY` for deployment base. GitHub Actions runs `npm test`, `npm run build` then publishes `dist` to Pages. Repository Settings → Pages → Source = GitHub Actions. URL: https://thiendinhylv.github.io/digital-zen-monastery/ **after successful workflow**.

## Security and content policy

- Do not place `OPENAI_API_KEY` or other secrets in `VITE_` or public files.
- Default browser uses curated knowledge search; it does not pretend a rule-based answer is a live LLM reply.
- No scoring of spiritual attainments, no purchase of merit, no unverified claims of canonical quotation.
- No account, tracking, or user conversation storage in static mode.
- Backend example is development-only; before exposing publicly, add operational monitoring, stronger rate limits, and human-reviewed source coverage.

See `docs/ASSET_PROVENANCE.md` and `docs/QA_REPORT.md` for evidence and remaining release blockers.
