# V1.3 source audit baseline

Baseline package: `digital-zen-monastery-v1.3-github-ready.zip`, created earlier in this conversation and used by the user to push 14 files (including `.gitignore`) to `ThienDinhYLV/digital-zen-monastery` on `main` at commit `173ae8e`. This audit directly read the baseline ZIP and compared the file listing with the Git CLI output supplied by the user. **It did not fetch the live GitHub repository**, which was inaccessible from this runtime.

- **Visual**: `src.js` builds trees with `IcosahedronGeometry` and mountains with `ConeGeometry`; monk uses spheres, a cone and a torus in a single group. No rigged GLB shipped at `public/assets/monk.glb`.
- **Architecture**: Vite `base` is correctly set from the repository. GitHub Actions has build/deploy jobs; user screenshot confirmed a subsequent workflow run succeeded.
- **Teaching**: static panel and mock replies; canonical source verification and no-source answers need a proper source index.
- **AI**: V1.3 has optional Express route. Static Pages cannot run `server.mjs` and so live LLM dialogue is not available on that hosting.
- **Security**: no API key in public project. A development server can be further hardened with origin allowlist and rate limits.
- **Visual QA**: screenshot supplied by the user shows working website, but a primitive, stylized low-poly pavilion and monk.

## V1.4 delta

- Repo includes a genuine skinned glTF2 file with 11 bones and a looping idle animation, generated by `tools/generate_monk.py`.
- Scene geometry improves with curved pavilion roof, many foliage clusters in one `InstancedMesh`, water and curved trunks; a scenic 2D backplate remains, so this is **hybrid 2D+3D rather than complete volumetric scenery**.
- Teaching is sourced to four SuttaCentral passages with conservative lookup, local no-source fallback and optional backend separate from Pages.
- Tests check app syntax, lookup integrity, GLB structure and workflow presence before Actions deploy.

## What V1.4 does NOT prove

- Browser rendering of the complete built bundle; local npm dependency registry not available in this runtime.
- Safari iPhone real-device performance.
- Photorealistic portrait, facial rig, complex pose transitions.
- End-to-end production AI dialogue; backend requires separate infrastructure.
